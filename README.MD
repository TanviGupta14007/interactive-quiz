# Interactive Quiz Application

## Description

This project is an interactive quiz application developed using HTML, CSS, and JavaScript. It allows users to answer quiz questions and interact with the quiz through a simple user interface.

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Files

* `index.html` – Defines the structure of the quiz application.
* `style.css` – Provides styling and layout for the application.
* `script.js` – Handles the quiz functionality and user interactions.

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Start using the quiz application.
